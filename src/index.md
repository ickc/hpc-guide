This guide collects practical advice for getting real work done on HPC systems:
how to submit your first jobs and find out what they used, how to build and
bootstrap software environments without `sudo`, how to run jobs efficiently, and
how to work with the storage and tooling you find on a typical cluster. If you are
new to clusters, start with [Getting started](getting-started/10-cluster.md).
